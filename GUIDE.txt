=====================================================
 출하 요청 / 주문서 메일 자동 작성기 - 사용 안내 (간단 버전)
=====================================================

이 프로그램은 엑셀(선박리스트·에어리스트)이나 주문서 PDF를 넣으면
업체별 메일을 Outlook "임시 보관함"에 초안으로 만들어 줍니다.
메일이 자동으로 나가지는 않습니다. Outlook에서 확인하고 직접 보내면 됩니다.


[ 1. 처음 한 번만 하는 준비 ]  (약 10분)

 (1) Python 설치
     - 인터넷에서 python.org 접속 → Downloads → "Download Python 3.x" 클릭
     - 설치 첫 화면 맨 아래 "Add python.exe to PATH" 체크박스를 꼭 켜고 → Install Now
       (이 체크를 안 하면 프로그램이 python을 못 찾습니다)

 (2) Outlook 확인
     - 회사 메일 Outlook이 로그인된 상태여야 합니다.
     - Outlook 오른쪽 위에 "새 Outlook" 스위치가 켜져 있으면 꺼 주세요. (클래식 Outlook이어야 함)

 (3) 프로그램 폴더 준비
     - shipment_mailer.zip 을 받아서 압축을 풉니다. (예: 바탕화면 또는 문서 폴더)
     - 폴더 안의 「1_install.bat」를 더블클릭합니다.
     - 검은 창이 뜨고 글자가 올라가다가 마지막에 "완료 (dry-run)" 이 보이면 성공입니다.
       (인터넷이 필요합니다. 빨간 글씨 오류가 나면 그 화면을 캡처해서 보내 주세요)


[ 2. 가장 쉬운 방법 - 브라우저 화면으로 실행 ]

 「0_run_web.bat」를 더블클릭하면 검은 창이 잠깐 뜨고 브라우저(엣지/크롬)에 화면이 열립니다.
   (검은 창은 최소화해 두세요. 끄면 화면도 멈춥니다. 다 쓰면 화면 오른쪽 위 "종료" 또는 검은 창 닫기)
   - 왼쪽 상자에 선박리스트·에어리스트 엑셀을 끌어다 놓기(또는 클릭해서 고르기)
       ① 미리보기 → 아래 "진행 내용"에 업체별 건수/받는 사람/미지정 품목이 나옵니다 (Outlook 안 씀)
       ② Outlook 임시 보관함에 초안 만들기 → 확인 창에서 "확인"
   - 오른쪽 상자에 주문서 PDF를 끌어다 놓기 → ① 미리보기 → ② 초안 만들기
   - 미지정 품목이 있으면 아래에 "③ 미지정 업체 지정하기" 표가 뜹니다.
       각 줄에서 업체를 고르고 "저장" → 다시 ① 미리보기
     (새 업체면 '(새 업체)'를 고르고 오른쪽 칸에 "업체이름, 메일주소"를 적으세요)
   - 위쪽 "Outlook에서 업체 정보 수집" 버튼: 최근 6개월 보낸 편지함을 읽어서
     비어 있는 받는사람·MAKER·거래처명을 자동으로 채웁니다. (이미 값이 있는 칸은 그대로 둠)
   - 설치(1_install.bat) 뒤에는 바탕 화면에 "MailMakerWeb" 바로가기가 생깁니다.


[ 2-1. 창(앱)으로 실행 - 브라우저 방식과 기능은 같습니다 ]

 「0_run_app.bat」를 더블클릭하면 창이 뜹니다.
   - 위쪽 "설정 파일": 보통 그대로 둡니다 (config.xlsx).
   - [출하 요청 메일] 탭: 선박리스트·에어리스트 "찾기"로 고르고
       ① 미리보기 → 아래 칸에 업체별 건수/받는 사람/미지정 품목이 나옵니다 (Outlook 안 씀)
       ② Outlook 임시 보관함에 초안 만들기 → 확인 창에서 "예"
   - [주문서 메일] 탭: PDF "추가" → ① 미리보기 → ② 초안 만들기
   - 미리보기에 "미지정 품목"이나 "업체를 못 찾음"이 나오면
       ③ 미지정 업체 지정하기 → 각 항목에 업체를 골라 "저장" → 다시 ① 미리보기
     (설정 파일을 직접 열지 않아도 됩니다. 새 업체면 '(새 업체)'를 고르고 "업체이름, 메일주소"를 적으세요)
   - "Outlook에서 업체 정보 자동 수집" 버튼: 최근 6개월 보낸 편지함의 주문서·출하 요청 메일을 읽어서
     비어 있는 받는사람·MAKER·거래처명을 자동으로 채웁니다. (이미 값이 있는 칸은 그대로 둠)
   - 빨간 글씨가 나오면 그 화면을 캡처해서 보내 주세요.

 아래 3~4번은 창 대신 끌어놓기 파일로 하는 방법입니다. 둘 중 편한 걸 쓰면 됩니다.


[ 3. 매주 월요일 - 출하 요청 메일 만들기 (끌어놓기 방식) ]

 (1) 선박리스트 엑셀과 에어리스트 엑셀 두 개를 함께 선택합니다.
     - 파일 이름에 "선박", "에어" 글자가 들어 있어야 자동으로 구분됩니다.
 (2) 두 파일을 「2_drop_excel_here.bat」 위로 끌어다 놓습니다.
 (3) 검은 창에 미리보기가 나옵니다.
     - 업체별 선박/에어 건수, 받는 사람, 제목
     - [미지정 품목] : 어느 업체인지 모르는 품목 (메일은 안 만들어짐)
     - [경고] 임시 보관함에 같은 주차 초안이 이미 있음 → 중복 주의
 (4) 내용이 맞으면 y 를 입력하고 Enter.  틀리면 그냥 Enter(취소).
 (5) Outlook → 임시 보관함(Drafts) 에 업체별 초안이 생깁니다. 열어서 확인하고 보내기.
     - 대아산업 메일은 맨 위에 빨간 "주문서 첨부 필요" 메모가 있습니다. 주문서 PDF 붙이고 그 줄은 지우고 보내세요.


[ 4. 주문서(발주서) 메일 만들기 (끌어놓기 방식) ]

 (1) ERP에서 주문서를 PDF로 저장합니다. (여러 업체, 여러 건이 한 파일이어도 됩니다)
 (2) 그 PDF를 「3_drop_po_pdf_here.bat」 위로 끌어다 놓습니다.
 (3) 미리보기 확인 → y → Outlook 임시 보관함에 업체별 "대아 주문서-번호" 메일이 생깁니다.
     - 한국단자공업, 연호전자, 경신전선은 자동으로 제외됩니다.
     - [업체를 못 찾음] 에 나오는 거래처는 config.xlsx 에 추가해야 합니다 (아래 5번).


[ 5. 업체·담당자가 바뀌었을 때 - config.xlsx 수정 ]

 config.xlsx 를 엑셀로 열어 「업체」 시트에서 고칩니다. 프로그램은 안 건드려도 됩니다.

   업체          : 업체 이름
   받는사람      : 메일 주소. 여러 명이면 쉼표(,)로 구분
   추가참조      : 그 업체에만 넣는 참조 주소
   수신줄        : 본문 첫 줄 (예: "수신: 이미경 실장님"). 필요 없으면 비움
   호칭          : "안녕하세요" 앞에 붙는 말 (예: 계장님). 비우면 안 붙음
   MAKER         : 선박/에어리스트의 MAKER 칸 값. 쉼표로 여러 개 (예: AMP, TE)
   엑셀첨부      : Y = 선박 표를 본문 대신 엑셀 첨부로 / N = 본문에 표
   메모          : 본문 맨 위에 빨간 글씨로 들어가는 메모 (보내기 전 지우는 용도)
   활성          : N 이면 이 업체는 무시
   거래처명(주문서) : 주문서 PDF의 "거래처명" 칸에 찍히는 이름
   발주서발송    : N 이면 주문서 메일을 안 만듦

 「품목지정」 시트 : 품목 코드(ITEM CD) 하나를 특정 업체로 보내고 싶을 때
                    (예: KET 품목 중 태양단자로 가는 것)
 「설정」 시트     : 공통 참조, 제목 형식, 서명 등


[ 7. 자주 나오는 문제 ]

 - "python은 내부 또는 외부 명령이 아닙니다"
     → Python 설치 때 "Add python.exe to PATH"를 안 켠 것. Python을 지우고 다시 설치.
 - "No such file or directory: '선박리스트.xlsx'"
     → 파일 이름이 다르거나 다른 폴더에 있음. 끌어놓기 방식으로 하면 생기지 않음.
 - Outlook 관련 오류
     → 클래식 Outlook이 켜져 있는지, "새 Outlook" 스위치가 꺼져 있는지 확인.
 - 헤더 행을 찾을 수 없습니다
     → 선박리스트에 "ITEM CD", "MAKER" / 에어리스트에 "Item cd", "Maker" 칸이 맨 위 40줄 안에 있어야 함.
 - 서명이 두 번 붙음
     → config.xlsx 「설정」 시트의 "서명" 칸을 비움.

 그 외 빨간 오류가 나오면 검은 창을 캡처해서 남효주에게 보내 주세요.


[ 6. 계장님 PC에 설치할 때 ]  ← 명령 프롬프트 전혀 안 씀

 방법 A (Python 설치 없이, 권장)
   1) 남효주 PC에서 「build_exe.bat」를 한 번 더블클릭 → dist\MailMaker 폴더가 생김 (5~10분)
   2) 그 폴더를 통째로 계장님 PC로 복사 (USB, 메신저 등)
   3) 폴더 안 config_kim.xlsx 를 config.xlsx 로 이름 바꾸기 (기존 config.xlsx 는 삭제)
   4) 「MailMakerWeb.bat」(브라우저 화면) 또는 「MailMaker.exe」(창) 더블클릭 → 끝. 바로가기는 exe 우클릭 → 보내기 → 바탕 화면에 바로 가기 만들기

 방법 B (Python 설치)
   1) python.org 에서 Python 설치 ("Add python.exe to PATH" 체크)
   2) zip 풀고 「1_install.bat」 더블클릭 → 바탕화면에 "메일 작성기" 바로가기가 자동 생성됨
   3) config_kim.xlsx 를 config.xlsx 로 이름 바꾸기

 공통

 - 폴더 안의 「config_kim.xlsx」가 계장님 이름·서명으로 미리 채워진 설정입니다.
   업체 표는 config.xlsx 와 같고(전 업체 공용), 주문서 메일 양식만 계장님 것입니다.
 - 계장님 PC에서는 기존 config.xlsx 를 지우고, config_kim.xlsx 의 이름을 config.xlsx 로 바꾸면 끝입니다.
 - 주문서 메일은 계장님 양식(제목 "기성-47198", 첨부 "기성-47198.pdf", 본문 3줄)으로 만들어집니다.
 - 한국단자공업·연호전자·경신전선은 주문서 메일을 만들지 않습니다.
 - 메일 주소를 못 찾은 업체: 삼풍, 뉴콘, 대성테크, SL, 부천공업, ASIREL, 엠이, 경신. 업체 시트에 채워 주세요.


[ 7. 계장님 설정(config_kim.xlsx)에 반영된 기존 메일 스타일 ]
 - 본문 전체 굵게, 11pt (설정 시트 본문굵게/본문크기로 바꿀 수 있음)
 - "수신: ○○○" 줄과 호칭을 쓰지 않음 (계장님 기존 메일 기준)
 - 주문서 제목 "{업체}-{PO}", 첨부 "{업체}-{PO}.pdf" (예: 기성-47198.pdf, 세일-47159.pdf)
 - 세일테크 주문서에는 "해당 납기일에 입고 부탁드립니다." 한 줄 추가 (업체 시트 주문서추가문구)
 - KET 주간 "긴급 자재의 건" 메일은 브라우저 버전(인터넷 주소로 여는 화면)에서 출하 요청 메일과 함께 만들어짐.
   이 폴더의 Python 프로그램에서는 다루지 않음. 경신/KET 엑셀 발주서는 기존대로 직접 발송
