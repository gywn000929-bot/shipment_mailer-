  1. 메일 작성기를 엽니다. 위쪽에 "처음 한 번만" 상자가 보입니다. 안 보이면 오른쪽 위 🔰 처음 확인을 누릅니다.
  2. 시험 메일 파일 받기를 누릅니다. 시험메일.eml 파일이 내려받아집니다. 받는 사람이 내 주소라서 실수로 보내도 괜찮습니다.

  4. 어떻게 열렸는지 화면에서 맞는 버튼 하나를 누릅니다. 그다음은 화면이 알려 주는 대로 하면 됩니다.

3출하 요청 메일

리스트 엑셀 하나로 업체별 메일이 한꺼번에 만들어집니다.

  1. 메일 작성기를 엽니다. 오른쪽 위에 "보내는 사람: 김민지 계장"이 맞는지 봅니다.
  2. 왼쪽 "출하 요청 메일" 칸의 선박리스트 자리에 리스트 엑셀을 끌어다 놓습니다. 에어 표가 같은 파일에 있으면 에어 칸은 비워 두어도 됩니다.
  3. 기준 주 월요일 날짜를 확인합니다. 이 날짜로 제목의 "○월 ○주"와 입고 요청 날짜가 정해집니다.
  4. 1. 미리보기 · 메일 만들기를 누릅니다.
  5. 아래에 업체별 메일 목록이 나옵니다. 본문 보기로 몇 개 열어 내용을 확인합니다.
  6. 📦 전부 받기 (ZIP)을 누릅니다.
  7. 받은 ZIP 파일을 마우스 오른쪽 버튼 → "압축 풀기".
  8. 폴더 안의 메일 파일을 하나씩 더블클릭합니다. Outlook 새 메일 창이 열리면 받는 사람과 첨부를 확인하고 보내기를 누릅니다.
  9. 보낸 메일은 화면 목록에서 "Outlook에서 보냈음"에 체크해 둡니다.
내 업체만 만들기"기준 주 월요일" 아래의 내 업체만을 체크하면 내가 맡은 업체의 메일만 만들어집니다. 다른 사람이 맡은 업체는 빠지고, 새로 생긴 업체는 자동으로 내 쪽에 들어옵니다. 한 번 켜 두면 이 PC가 기억합니다. 누가 어느 업체를 맡는지는 "✉ 메일 문구 고치기 → 그 밖의 설정"의 "내업체" · "내업체제외" 칸에서 바꿉니다.

3-1화요일 에어 · 금요일 에어

제일 빠른 방법: 아무 곳에나 끌어다 놓기받은 엑셀이나 주문서 PDF를 메일 작성기 화면 아무 곳에나 끌어다 놓으면, 어떤 메일인지 알아서 고르고 바로 만듭니다. REMAIN 메일 본문의 표는 화면에서 그냥 Ctrl+V 해도 됩니다. 기준 주(○월 ○째주)도 리스트의 NEED ETD 날짜를 보고 자동으로 맞춥니다.

에어는 일주일에 두 번 요청합니다. 어느 쪽인지는 넣은 엑셀을 보고 화면이 알아서 정합니다.

월요일: 화요일 에어 (주간 리스트와 함께)

  • 출하 요청 메일을 만들면 에어 표가 함께 들어갑니다. 따로 누를 것은 없습니다.
  • 에어 표에 들어가는 품목: KET 품목은 전부, "에어 장납" 시트에 있는 품목도 전부, 나머지 업체는 NEED ETD가 URGENT인 품목만.
  • "진행 내용"에 [화요일 에어] ○건 중 ○건 요청: KET 전체 ○건 + 에어 장납 ○건 + URGENT ○건처럼 나옵니다. 숫자가 이상하면 리스트를 확인하세요.
  • 리스트에 "에어 장납" 시트가 없는 주에는 이 PC가 지난번에 읽은 장납 목록을 씁니다(진행 내용에 노란 글씨로 알려 줍니다).

수요일: 금요일 에어 (REMAIN 리스트)

  1. 남효주가 보낸 "금주 금요일 에어 REMAIN 리스트" 메일의 첨부 엑셀을 받습니다(바탕화면 등 아무 곳에 저장).
  2. 메일 작성기 맨 위 "오늘 만들 메일은?"에서 ✈ 수요일 REMAIN 메일을 고릅니다(수·목요일에 열면 처음부터 골라져 있습니다).
  3. 나온 "금요일 에어 메일" 칸에 메일 본문의 표를 붙여 넣거나, 그 아래 칸에 REMAIN 엑셀을 그대로 끌어다 놓습니다.
  4. 1. 미리보기 · 메일 만들기 → 진행 내용 맨 위에 [금요일 에어]가 보이면 맞게 읽힌 것입니다.
  5. 업체별 메일이 나옵니다. 제목 끝에 (금요일 에어), 본문에 "금주 금요일 에어 리스트"와 금요일 입고 요망일, Remain(노란색) 표가 들어갑니다.
  6. 📦 전부 받기 (ZIP) → 압축 풀고 하나씩 더블클릭 → 보내기. 보낸 메일은 "Outlook에서 보냈음" 체크.
엑셀 대신 메일 본문의 표를 복사해 붙여 넣어도 됩니다메일 작성기 아래쪽의 "금요일 에어 메일" 칸을 씁니다. REMAIN 메일 본문의 표를 맨 윗줄(FAC, Item cd …)부터 마지막 줄까지 선택해 Ctrl+C → 큰 칸을 클릭하고 Ctrl+V → 칸 아래에 "✔ 품목 ○줄"이 나오면 그 칸의 미리보기 · 메일 만들기. 업체는 화면에 미리 들어 있는 거래처 표로 나눕니다.
Remain은 어떻게 계산되나요?엑셀 AIR 시트의 Purchase request − 출고수량입니다. 0 이하인 품목(화요일에 다 나간 것)은 빠집니다. 수요일 메일 본문의 REMAIN 표와 같은 숫자인지 한두 업체만 맞춰 보세요.
기준 주는 이번 주로 자동으로 잡힙니다수요일에 열면 기준 주가 "이번 주 월요일"로 바뀌고, 입고 요망일은 그 주 금요일이 됩니다. 다른 주 것을 만들 때만 기준 주 날짜를 직접 바꾼 뒤 다시 누르세요.
월요일 메일과 따로 기록됩니다같은 업체라도 월요일 출하 요청 메일과 금요일 에어 메일은 따로 기록하므로 "이미 만든 메일"로 막히지 않습니다. 금요일 에어를 두 번 만들 때만 빨간 테두리가 나옵니다.

4KET 긴급 자재 메일

따로 누를 것은 없습니다. 출하 요청 메일을 만들 때 함께 만들어집니다.

  • 에어리스트에 KET 품목이 있으면, 목록에 빨간 "긴급 자재" 표시가 붙은 메일이 하나 더 나옵니다.
  • 본문에는 NO · 품목명 · 미납수량 합계 · AIR 수량 · 부족일정 표가 들어갑니다. 부족일정이 URGENT이거나 기준 주 안이면 그 줄이 붉게 칠해집니다.
보내기 전에 표를 꼭 확인하세요이 메일의 표 모양과 숫자 기준은 실제로 보내던 메일과 아직 맞춰 보지 못했습니다. 특히 "미납수량 합계" 숫자가 맞는지 확인하고, 다르면 Outlook 창에서 고친 뒤 보내세요.

5주문서 메일

전산에서 뽑은 주문서 PDF를 넣으면 업체별로 잘라서 메일을 만듭니다.

  1. 메일 작성기 오른쪽 "주문서(발주서) 메일" 칸에 주문서 PDF를 끌어다 놓습니다. 한 파일에 여러 업체, 여러 주문서가 섞여 있어도 되고, 파일을 여러 개 넣어도 됩니다.
  2. 1. 미리보기 · 메일 만들기를 누릅니다.
  3. "PDF에서 읽은 주문서 ○건 보기"를 눌러 PO 번호와 업체가 맞게 읽혔는지 봅니다.
  4. 그다음은 출하 요청 메일과 같습니다. 전부 받기 → 압축 풀기 → 더블클릭 → 보내기.
  • 제목은 업체-PO번호 (예: 기성-48015), 첨부 파일 이름도 같습니다.
  • 주문서를 보내지 않는 업체(KET, 경신, JST, 연호엠에스, 정우 RTI 등)는 자동으로 건너뜁니다.
  • 같은 PO 번호로 이미 메일을 만든 적이 있으면 빨간 테두리로 알려 줍니다.
스캔한 PDF는 읽지 못합니다종이를 스캔한 그림 PDF에는 글자가 없어서 PO 번호를 읽을 수 없습니다. 전산에서 바로 저장한 PDF를 넣어 주세요.

6입고 파일 만들기

업체가 입고수량을 적어 보낸 엑셀을, 전산에 올리는 엑셀(1118 태양기전.xlsx 모양)로 바꿉니다.

  1. 입고 파일 만들기 화면을 엽니다.
  2. 업체가 회신한 엑셀을 끌어다 놓습니다. 여러 업체 것을 한꺼번에 넣어도 됩니다.
  3. 업체 이름과 업체코드가 자동으로 채워졌는지 봅니다. 파일 이름에 업체 이름이 들어 있으면 알아서 고릅니다. 틀리면 고르는 칸에서 바꿉니다.
  4. 입고 날짜를 고릅니다. 파일 이름 앞 4자리(예: 1118)가 됩니다.
  5. 수량 보기·고치기를 눌러 입고수량을 확인합니다. 요청 수량과 다른 줄은 노란색으로 보입니다.
  6. 📥 받기를 누릅니다. 여러 업체면 📦 전부 받기 (ZIP).
  7. 받은 엑셀을 전산에 올립니다. (올리는 것은 직접 하셔야 합니다)

이 화면이 해 주는 일

  • 이번 주(첫 ETD) 요청 수량이 있는 줄만 남깁니다.
  • 공장을 전산 코드로 바꿉니다: F1 → 1010, F2 → 1060, F5 → 1150.
  • 업체코드 칸을 넣습니다 (예: 태양기전 4350).
업체가 수량을 안 적고 "요청대로 보냈습니다"라고만 했다면빈칸을 요청 수량대로를 누르면 전부 요청 수량으로 채워집니다. 그다음 다른 줄만 고치세요. 안 들어온 품목은 칸을 지워 비워 둡니다.
업체가 엑셀 없이 메일 본문으로만 답했다면주간 리스트 엑셀을 넣으세요. 업체별로 나눠서 보여 주니, 해당 업체의 입고수량만 적으면 됩니다.
"업체코드가 없습니다"라고 나오면기성전선, 명보케이블, 동성폴리머는 아직 코드가 들어 있지 않습니다. 그 칸에 코드를 직접 적으면 이 PC가 기억합니다.

7업체 정보 고치기

담당자 메일이 바뀌거나 새 업체가 생겼을 때 합니다.

급할 때: 그 자리에서 메일 주소만 넣기

메일 목록에 "받는 사람 없음"이 뜨면, 그 줄의 빈칸에 메일 주소를 적고 "저장"을 누르면 바로 메일이 만들어집니다.

제대로 고치기

  1. 메일 작성기 오른쪽 위 🏢 업체 주소를 누릅니다.
  2. 표에서 고칠 칸을 눌러 바로 고칩니다. 메일 주소가 여러 개면 쉼표(,)로 나눠 적습니다.
  3. 새 업체는 + 업체 추가. 이제 안 쓰는 업체는 지우지 말고 "사용" 체크를 끕니다.
  4. 저장하고 설정 파일 받기 (다른 PC에도 적용)를 누릅니다.
  5. 화면에 올리는 방법이 나옵니다. 링크를 눌러 열린 화면에 받은 파일을 끌어다 놓고, 아래 초록색 Commit changes 버튼을 누릅니다.
  6. 2~3분 뒤 메일 작성기를 새로 고치면(F5) 위쪽 노란 알림이 사라집니다. 사라졌으면 끝입니다.
표의 칸무엇을 적나
받는 사람 메일그 업체 담당자 메일. 빨간 칸은 비어 있다는 뜻입니다.
이 업체만 참조 추가그 업체 메일에만 더 들어갈 참조. 공통 참조는 따로 자동으로 들어갑니다.
주문서·리스트에 적힌 업체 이름리스트나 주문서에 찍히는 다른 표기. 여러 개면 쉼표로.
출하 요청 메일 / 주문서 메일체크를 끄면 그 업체로는 그 메일을 만들지 않습니다.
전산 업체코드입고 파일의 업체코드 칸에 들어갈 번호.
위쪽 노란 알림 "이 PC에만 저장된 설정 변경 ○건"고친 내용이 아직 이 PC에만 있다는 뜻입니다. 다른 PC에서 열면 보이지 않습니다. 설정 파일 받아서 올리기를 눌러 올려야 어디서나 적용됩니다.
올리기가 어려우면올리는 화면은 GitHub 로그인이 필요합니다. 계정이 없거나 어렵다면 받은 설정 파일을 남효주에게 메일로 보내 주세요. 그동안 이 PC에서는 고친 대로 계속 쓸 수 있습니다.

막힐 때 보는 곳

화면이 예전 모양이거나 버튼이 안 보여요.

Ctrl 키를 누른 채 F5를 눌러 새로 고치세요.

메일 파일을 더블클릭했는데 Outlook이 안 열려요.

파일을 마우스 오른쪽 버튼 → 연결 프로그램 → 다른 앱 선택 → Outlook → "항상". 그래도 안 되면 메일 작성기의 "🔰 처음 확인"에서 "다른 프로그램이 열렸다"를 눌러 안내를 따라 하세요.

메일은 열리는데 "보내기" 버튼이 없어요.

Outlook 오른쪽 위 "새 Outlook" 스위치를 끄고 다시 해 보세요. 스위치가 없으면 메일 줄의 다른 방법을 누르면 1. 새 메일 창 열기 2. 본문 복사 3. 첨부 받기 버튼이 나옵니다. 새 메일 창 본문에 Ctrl+V로 붙이고 첨부를 끌어다 놓으면 됩니다.

서명이 두 번 들어가요 / 서명이 없어요.

메일 작성기 → "고급 설정" → "본문 끝에 서명 넣기"를 끄거나 켭니다.

업체가 목록에 안 나와요.

세 가지 중 하나입니다. 이번 주 수량이 없거나, 메일을 보내지 않는 업체로 되어 있거나("건너뜀"에 나옵니다), 리스트의 거래처 이름을 못 찾았거나("업체를 모르는 품목"에 나옵니다).

"이미 만든 적이 있는 메일"이라고 나오는데 실제로는 안 보냈어요.

메일 파일을 받기만 하고 보내지 않은 경우입니다. Outlook 보낸 편지함에 없는 것을 확인하고 "포함"을 켠 뒤 받으면 됩니다.

다른 PC에서 열었더니 고친 메일 주소가 없어요.

고친 내용을 올리지 않아서입니다. 고쳤던 PC에서 노란 알림의 "설정 파일 받아서 올리기"를 하세요.

리스트 만들기에서 파일을 넣었는데 "쓸 수 있는 표를 찾지 못했습니다"라고 나와요.

요청 파일이 아닌 다른 파일이거나, 시트 이름이나 머리글이 평소와 다른 경우입니다. 받은 원본 그대로 넣었는지 확인하세요.

에어 표가 엉뚱한 시트에서 읽혔어요.

월요일 주간 리스트(선박 표가 있는 파일)는 원래 Air 시트를, 수요일 REMAIN 리스트(선박 표가 없는 파일)는 출고수량·Remain 열이 있는 시트(AIR)를 씁니다. 다른 시트를 쓰려면 파일을 넣은 칸 아래 "에어 시트"에서 고르세요.

화요일 에어 표에 URGENT가 아닌 품목도 넣고 싶어요.

KET처럼 늘 전부 넣을 업체는 "✉ 메일 문구 고치기 → 그 밖의 설정"의 화요일에어전체업체 칸에 쉼표로 추가합니다. 한 주만 전부 넣으려면 고급 설정의 "화요일 에어" 체크를 끕니다.

메일 문구 고치기

두 가지 방법이 있습니다. 한 번만 바꿀 때와 앞으로 계속 바꿀 때입니다.

이 메일 한 통만 고치기

  1. 미리보기 후 나온 메일 목록에서 그 업체 줄의 ✏ 고치기를 누릅니다.
  2. 제목 칸과 본문을 바로 고칩니다. 본문은 글자를 눌러 지우고 적으면 되고, 표 안 숫자도 고칠 수 있습니다(Ctrl+B 굵게).
  3. 고친 내용 저장 → 그 줄에 "✏ 고친 메일"이 붙고, 메일 파일 받기/ZIP에 고친 내용이 들어갑니다. 되돌리려면 원래대로.
미리보기를 다시 누르면 고친 내용은 없어집니다다 고친 뒤 바로 받으세요.

앞으로 계속 쓸 문구 바꾸기

  1. 위쪽 ✉ 메일 문구 고치기를 누릅니다.
  2. 고칠 메일을 고릅니다: 📅 월요일 출하 요청 · ✈ 금요일 에어 · 📄 주문서 · 🚨 KET 긴급 자재.
  3. Outlook 새 메일 창처럼 생긴 화면에서 참조 · 제목 · 본문 · 서명을 눌러 바로 고칩니다. 본문 글꼴(맑은 고딕·굴림·돋움·바탕·궁서·Arial·Calibri·Tahoma), 굵게, 글자 크기도 여기서 바꿉니다.
  4. 회색 칸은 메일을 만들 때 자동으로 채워지는 부분입니다(표, 날짜, 업체 이름 등). 필요 없으면 지우고, 끌어서 옮길 수 있습니다. 첫 줄 인사 칸은 눌러서 "✎ 고치기"하면 보통 글자로 바뀌어 직접 고칠 수 있습니다.
  5. 표 칸 위의 "선박리스트 (노란색 수량, ○/○일 입고 요망)", "에어리스트 (…)", 엑셀 첨부 업체용 안내 문구도 눌러서 바로 고칩니다. 날짜만 자동입니다. 줄을 다 지우면 그 줄은 메일에 넣지 않습니다.
  6. 저장하고 설정 파일 받기(다른 PC에도 적용) 또는 이 PC에만 저장. 잘못 고쳤으면 ↺ 이 메일 원래대로.

참조·서명·글꼴·굵게·글자 크기는 모든 메일에 함께 적용됩니다.

꼭 직접 확인할 것

아래는 사람이 한 번 더 봐야 하는 부분입니다.

  • 보내기 전에 받는 사람과 첨부를 확인하세요. 이 화면은 메일을 만들 뿐이고, 맞는지 보는 것은 보내는 사람 몫입니다.
  • 실제로 보냈는지는 Outlook 보낸 편지함이 기준입니다. "이미 만든 적이 있는 메일" 표시는 이 PC에서 메일 파일을 받은 기록일 뿐입니다. PC를 바꾸면 그 기록은 없습니다.
  • KET 긴급 자재 메일의 표는 실제 메일과 아직 맞춰 보지 않았습니다. 숫자를 확인하세요.
  • 입고 파일의 입고수량은 업체가 적은 값이나 내가 적은 값이 그대로 들어갑니다. 전산에 올리기 전에 한 번 훑어보세요.
  • 리스트의 출고수량, 컨펌은 자동으로 만들어지지 않습니다. 출고수량은 남효주가 적어 수요일에 보내 주는 엑셀에 들어 있습니다.
  • 연호엠에스는 출하 요청 메일을 보내지 않는 업체라, 에어 리스트에 있어도 메일이 만들어지지 않습니다("건너뜀"에 표시).

고쳐야 할 점이나 안 되는 것이 있으면 화면을 캡처해서 남효주에게 알려 주세요.
