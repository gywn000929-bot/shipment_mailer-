출하 요청 메일 자동 작성기

매주 선박리스트·에어리스트 엑셀을 넣으면 업체별 출하 요청 메일을 **Outlook 임시 보관함(Drafts)** 에 초안으로 만들어 줍니다.
자동 발송은 하지 않습니다. Outlook에서 확인한 뒤 직접 보내세요.

## 방식 선택 이유
Windows 데스크톱 Outlook + Python(win32com)을 씁니다.
- 회사 PC에 Outlook만 설치되어 있으면 추가 권한·앱 등록 없이 바로 동작합니다.
- Outlook 기본 서명이 자동으로 붙습니다.
- 임시 보관함을 직접 읽어 같은 주차 초안 중복을 경고할 수 있습니다.
- Graph API는 IT 관리자의 앱 등록(테넌트 권한)이 필요해 제외했습니다.

※ "새 Outlook"(New Outlook, 파란 토글)은 COM을 지원하지 않습니다. 클래식 Outlook이어야 합니다.
   새 Outlook만 있으면 Outlook 우측 상단 "새 Outlook" 토글을 꺼서 클래식으로 전환하세요.

## 설치 (최초 1회)
1. Python 3.10 이상 설치 (python.org, "Add to PATH" 체크)
2. `1_install.bat` 더블클릭 (패키지 설치 + 샘플 테스트). 또는 이 폴더에서:
   ```
   pip install -r requirements.txt
   ```

## 사용
가장 쉬운 방법: `0_run_web.bat` 더블클릭 → 브라우저 화면에 엑셀/PDF를 끌어다 놓고 ① 미리보기 → ② 초안 만들기. (추가 설치 없음)

창(앱) 방식: `0_run_app.bat` (tkinter). 기능은 같습니다.

명령줄:
```
python make_drafts.py --ship 선박리스트.xlsx --air 에어리스트.xlsx
```
또는 `2_drop_excel_here.bat` 위에 두 엑셀 파일을 함께 끌어다 놓으면 됩니다(파일명에 "선박"/"에어"가 있어야 자동 구분).

실행 흐름:
1. 미리보기 출력: 업체별 선박/에어 건수, 받는 사람, 제목, 문제(받는 사람 없음 등), 미지정 품목
2. 임시 보관함에 같은 주차 초안이 이미 있으면 경고
3. `y` 입력 시 업체별 초안 생성 + 업체별 엑셀 첨부 생성(`output/` 폴더)
4. 미지정 품목은 `output/미지정_품목_….xlsx`에 저장되고 메일은 만들지 않음

### 자주 쓰는 옵션
| 옵션 | 설명 |
|---|---|
| `--etd 3` | 메일에 넣을 ETD 열 개수(앞에서부터). 기본은 설정 시트의 값(3) |
| `--etd-cols "27-NOV-26,04-DEC-26"` | ETD 열을 이름으로 직접 지정. 첫 번째가 "이번 주"(노란색) |
| `--week-monday 2026-11-23` | 기준 주 월요일. 기본은 다음 주 월요일 |
| `--air-date`, `--ship-date` | 입고 요망일 직접 지정. 기본은 기준 월요일+1(화), +2(수) |
| `--only "대일CST,태양단자"` | 일부 업체만 생성(중복 생성 피할 때) |
| `--dry-run` | Outlook 없이 `output/`에 HTML 미리보기만 저장 |
| `-y` | 확인 질문 생략 |
| `--config 다른설정.xlsx` | 다른 설정 파일 사용 |

## 설정 파일 `config.xlsx` (직접 수정)
- **업체** 시트: 업체 / 받는사람 / 추가참조 / 수신줄 / 호칭 / MAKER / 엑셀첨부 / 메모 / 활성
  - MAKER, 받는사람, 참조는 쉼표로 여러 개.
  - 메모(예: 대아산업 "주문서(PDF) 첨부 필요")는 본문 맨 위에 빨간 띠로 들어갑니다. 보내기 전 지우세요.
  - 성우실업·대아산업·태양기전·연호는 MAKER/이메일이 미확인 상태로 비워 두었습니다. 채우기 전까지는 해당 품목이 "미지정"으로 나옵니다.
- **품목지정** 시트: ITEM CD → 업체. MAKER 매핑보다 우선합니다. KET 품목을 태양단자/KET 직접으로 나눌 때 사용.
- **설정** 시트: 공통참조, 발신자소개 문구, ETD열개수, 서명(Outlook 기본 서명이 없을 때만 사용)

업체 결정 우선순위: 선박리스트 `업체` 열 > 품목지정 시트 > MAKER 매핑.
MAKER가 비어 있으면 품명 끝의 `(메이커)`에서 뽑습니다.

## 메일 양식 (기존 발송 메일 기준)
제목: `대아홀딩스 11월 3주 출하 요청의 건` (에어만 있으면 끝에 `(에어)`). 설정 시트 "제목형식"에서 변경.

- **엑셀첨부=Y 업체** (반도기전 진영/김해, 대일CST, 태양기전): 본문에 선박 표를 넣지 않고 엑셀만 첨부.
  첨부 엑셀 열: Fac | ITEM CD | MAKER | ITEM NM | 이번 주 ETD(노란색) | 입고수량(업체가 기재) | 다음 ETD
  ```
  안녕하세요. 대아홀딩스 남효주 입니다.
  첨부 내용으로 금주 선박 리스트 송부 드립니다.
  선박리스트 (노란색 수량, 11/18일(수) 입고 요망)
  첨부 선박 리스트는 자재 입고 전 입고수량 기재하여 회신 부탁드립니다.

  에어리스트 (노란색 수량, 11/17일(화) 입고 요망)
  [표]
  감사합니다.
  ```
- **엑셀첨부=N 업체**: "하기 내용으로 금주 선박 리스트 송부 드립니다." + 본문에 선박 표(이번 주 열 노란색).
- 에어 표: FAC | Item cd | Maker | Part Name | Purchase request(노란색) | (Short Del.) | NEED ETD
- 설정 "수량없는행포함"=Y 이면 기존 메일처럼 그 업체의 전체 품목(수량 0 포함)을 표/첨부에 넣습니다. 이번 주 수량이 하나도 없는 업체는 메일을 만들지 않습니다.

## 주문서(발주서) 메일: `make_po_mails.py`
ERP에서 한 번에 뽑은 주문서 PDF(여러 업체·여러 PO가 한 파일)를 넣으면 PO별 PDF로 나누고 업체별 초안을 만듭니다.
```
python make_po_mails.py 주문서.pdf              (또는 3_drop_po_pdf_here.bat 에 끌어놓기)
python make_po_mails.py 주문서.pdf --dry-run    (Outlook 없이 PDF 분리 + HTML만)
```
- 제목 `대아 주문서-48010,48011`, 첨부 `48010.pdf`, `48011.pdf` (기존 메일과 같음)
- 본문: 안녕하세요. 대아홀딩스 남효주 입니다. / 수고 많으십니다. / 상기 제목에 따라 주문서 송부하오니 / 첨부파일 확인 및 수신 여부 회신 부탁드리겠습니다. / 감사합니다.
- 업체는 PDF의 "거래처명"을 config 업체 시트 `거래처명(주문서)` 열과 맞춰 찾습니다. 못 찾으면 미리보기에 표시되고 메일을 만들지 않습니다.
- `발주서발송`=N 업체(한국단자공업, 연호전자, 경신전선)는 PDF만 나누고 메일은 만들지 않습니다.
- 스캔 이미지 PDF는 글자를 못 읽으니 ERP에서 바로 저장한 PDF를 쓰세요.
- 임시 보관함에 같은 PO 번호 초안이 이미 있으면 경고합니다.

## 설정 자동 채우기
- 앱의 **③ 미지정 업체 지정하기**: 미리보기 후 미지정 MAKER / 못 찾은 거래처명을 업체에 연결해 config.xlsx에 바로 저장.
- 앱의 **Outlook에서 업체 정보 자동 수집** (`learn_from_outlook.py`): 보낸 편지함의 주문서 PDF에서 거래처명을 읽어 받는사람·참조·호칭·수신줄을, 출하 요청 메일 표에서 MAKER를 뽑아 빈 칸만 채움. `--dry-run`으로 미리 볼 수 있음.

## 담당자별 설정 파일
- `config.xlsx` : 남효주 기준 (출하 요청 + 주문서)
- `config_kim.xlsx` : 김민지 계장 기준. 계장님 PC에서는 이 파일을 `config.xlsx`로 이름을 바꿔 쓰거나 `--config config_kim.xlsx`로 지정.
- 설정 시트에서 바뀌는 것: 발신자소개, 서명, 공통참조, 주문서제목형식(`{업체}-{PO}` 또는 `대아 주문서-{PO}`), 주문서첨부이름, 주문서본문(줄 단위 템플릿, `{추가문구}` 자리에 업체별 문구).

## 주차 계산
기준 주 월요일 + 3일(목요일)이 속한 달과 `ceil(일/7)`.
예: 11/9 주 → 11월 2주, 10/26 주 → 10월 5주, 11/30 주 → 12월 1주.

## 문제 해결
- `pywin32가 없습니다` → `pip install pywin32`
- Outlook 연결 오류 → 클래식 Outlook이 실행 중인지, 새 Outlook 토글이 꺼져 있는지 확인
- 헤더를 못 찾음 → 선박리스트는 "ITEM CD"와 "MAKER", 에어리스트는 "Item cd"와 "Maker"가 처음 40행 안에 있어야 함(대소문자·공백 무시)
- 초안에 서명이 두 번 붙음 → Outlook 옵션의 "새 메시지 서명"이 켜져 있으면 자동 서명을 쓰고, 설정 시트 서명은 무시됩니다. 두 번 붙으면 설정 시트의 서명 칸을 비우세요.

### 주간 리스트 만들기 (`list.html`, `js/build.js`)
받은 파일을 그대로 넣으면 `선박 및 에어리스트` 엑셀을 만든다. 엑셀 매크로 `선박리스트_만들기`와 같은 규칙이며, 실제 한 주 치 파일로 완성본과 대조했다(선박 822줄 × 16열 일치).
- 선박: 요청 파일의 `SUMMARY*` 시트에서 ITEM NM 바로 뒤 열들이 ETD 수량(F2처럼 머리글에 날짜가 없으면 시트 이름의 ETD 날짜 사용). SUM이 0인 줄은 제외
- BALANCE/STOCK: `F1 Bal`, `F2 JST Bal`, `F2 Sto` 같은 이름의 시트(또는 파일 이름)에서 품목 코드로 조회. MAKER가 JST이고 비어 있으면 JST 시트에서 다시 조회
- BALANCE 1 = BALANCE + STOCK, B-R = BALANCE 1 − SUM
- 거래처: 예외표의 M코드가 같고 품목명이 예외 품목명으로 시작 → 품목명이 예외 품목명과 같음 → MAKER별 기본 거래처
- 정렬: FAC → MAKER → 품목명(엑셀처럼 하이픈 무시)
- 에어: 리포트의 `600>>2,100`은 2,100으로, `500>>0`은 제외
- 거래처 표는 한 번 넣으면 브라우저가 기억한다. 틀 고정은 넣지 못했다(엑셀에서 직접)

### 입고 파일 만들기 (`inbound.html`, `js/inbound.js`)
업체가 입고수량을 적어 회신한 엑셀(또는 주간 리스트)을 전산에 올리는 엑셀(`1118 태양기전.xlsx` 모양)로 바꾼다. 실제 한 쌍(보낸 파일 → 올린 파일)으로 대조했다(37줄 × 7열 일치).
- 첫 ETD 열 요청 수량이 있는 줄만, 원래 순서대로
- Fac → 수주처 코드(설정 `공장코드`: F1=1010, F2=1060, F5=1150)
- 열: 수주처 코드 | ITEM CD | MAKER | 업체코드 | ITEM NM | 요청 수량 | 입고수량
- 업체는 파일 이름에 들어 있는 업체 이름(별칭 포함)으로 찾고, 업체코드는 업체 시트의 `업체코드` 열에서 가져온다

### 설정 파일의 기준
- 브라우저에서 고쳐 GitHub에 올린 `config*.xlsx` 가 기준이다. `make_config.py --force` 는 엑셀이 `VENDORS` 와 다르면 멈춘다(엑셀 내용을 `VENDORS` 로 먼저 옮기거나 `--discard-web-edits`).
- `config.xlsx`(남효주)와 `config_kim.xlsx`(계장님)의 업체 시트는 따로 관리된다. 한쪽에서 고친 메일 주소는 다른 쪽에도 같이 고쳐야 한다.
- 긴급 자재 메일·서명 끄기·설정 편집 화면은 브라우저 버전에만 있다(Python 버전에는 없음).

### 확인하지 못한 것
- 실제 Windows + Outlook에서 .eml 이 새 메일 창으로 열리는지(클래식 Outlook 기준으로 만든 방식이며, "새 Outlook"에서는 보내기 창으로 열리지 않을 수 있음).
- 긴급 자재 메일의 표 모양·붉은 음영 기준·본문 문구가 계장님이 실제로 보내던 메일과 같은지(실제 메일 한 통과 대조 필요).

### 수주 등록 확인 (`check.html`, `js/check.js`)
태국 주문서 원본(여러 개)과 전산 수주현황 엑셀을 한꺼번에 넣으면 줄마다 맞춰 봅니다.
- 짝: 주문서 `Order No`+`Seq` ↔ 수주현황 `수주번호`+`수주순번`
- 항상 비교: 수주수량, 품명(공백·대소문자 무시, 수주현황의 깨진 글자 `?`는 아무 글자로 봄), 공장(주문번호 앞 2자리 F1→거래처 1010, F2→1060. `js/check.js`의 `CK_FACTORY`), 수주현황 안의 중복, 고객주문번호≠수주번호
- 선택 비교: 규격·단위(기본 켬), 납기일자·단가(기본 끔)
- 결과: 수량 다름 / 품명 다름 / 순번 다름 / 빠짐 / 남는 줄 / 중복 등록 / 공장 다름, 수주현황에 없는 주문서, 원본을 안 넣은 주문
