업체별로 본문·첨부 엑셀을 만들어 아래에 보여 줍니다. 내 PC 밖으로 나가는 것은 없습니다(모두 이 브라우저 안에서 처리).

1 주문서(발주서) 메일

주문서 PDF를 여기에 끌어다 놓거나 클릭 (여러 개 가능)아직 없음
한 PDF에 여러 업체·여러 PO가 있어도 됩니다. 업체별로 잘라서 "업체-PO번호" 메일을 만듭니다. 발주서발송=N 업체(한국단자공업·연호·경신)는 자동 제외.

2 만들어진 메일

받은 .eml 파일을 더블클릭하면 Outlook에 받는 사람·제목·본문·첨부가 채워진 새 메일 창이 열립니다. 내용 확인 후 보내기만 누르세요. (자동 발송 없음) · 보내지 않을 업체는 왼쪽 "포함" 체크를 끄세요.
다음 할 일: 받은 ZIP을 우클릭 → "압축 풀기" → 폴더 안의 .eml 파일을 하나씩 더블클릭 → Outlook 새 메일 창에서 받는 사람·첨부를 확인하고 보내기. 다 보낸 뒤에는 폴더를 지워도 됩니다.

3 미지정 업체 지정하기

아래 항목을 어느 업체로 보낼지 고르고 저장하세요. 새 업체면 "(새 업체)"를 고르고 오른쪽에 업체이름, 메일주소를 적습니다. 저장 후 ① 을 다시 누르세요. (이 브라우저에 기억되며, "설정 내려받기(수정본)"으로 엑셀에 합칠 수 있습니다)

사용법

  1. 위에서 설정 파일을 고릅니다. 계장님은 config_kim.xlsx (김민지 계장).
  2. 선박리스트·에어리스트 엑셀(또는 주문서 PDF)을 끌어다 놓고 ① 미리보기 · 메일 만들기.
  3. 업체별 메일이 아래에 나옵니다. "본문 보기"로 확인하고 📦 전부 받기 (ZIP) 또는 메일마다 "메일 파일 받기".
  4. 받은 ZIP의 압축을 풀고 .eml 파일을 더블클릭 → Outlook 새 메일 창 → 내용 확인 → 보내기.
    .eml이 Outlook이 아닌 다른 앱으로 열리면: 파일 우클릭 → 연결 프로그램 → Outlook 선택(항상 이 앱 사용 체크).
  5. "미지정 품목"이 나오면 ③에서 업체를 골라 저장하고 ①을 다시 누릅니다. "받는 사람 없음" 업체는 그 칸에 메일 주소를 적고 저장하면 됩니다. 저장한 내용은 이 브라우저에 기억되고, "설정 내려받기(수정본)"로 엑셀에 합쳐 GitHub에 올리면 다른 PC에서도 적용됩니다.
  6. 선박리스트 파일 안에 Air 시트가 같이 있으면 선박 칸에만 넣어도 에어까지 자동으로 만듭니다. 에어 표가 여러 시트(Air, Air up)면 Remain 열이 있는 시트를 쓰고, 파일 아래 "에어 시트"에서 바꿀 수 있습니다.
  7. 보내지 않을 업체는 메일 목록의 "포함" 체크를 끄면 ZIP에서 빠집니다. 같은 제목으로 이미 받은 적이 있으면 경고가 뜹니다(중복 발송 방지).
보낸 편지함 서명은 자동으로 붙지 않으므로 설정 시트의 "서명"이 본문 끝에 들어갑니다. 같은 주에 이미 보낸 메일이 있는지는 Outlook 보낸 편지함에서 직접 확인하세요.
